# Formulario de Inicio de Sesión

Este proyecto es una práctica de front-end que consiste en una interfaz de formulario para iniciar sesión. Está construida con HTML y CSS puro, con un diseño moderno, limpio y responsive.

## Descripción

La página incluye:

- Un formulario de acceso con campos para nombre, usuario y contraseña
- Diseño centrado en pantalla
- Estilo visual elegante con bordes, sombras y transiciones
- Animación del texto de etiquetas al interactuar con los inputs
- Botón de envío con color destacado

## Tecnologías utilizadas

- HTML5
- CSS3
- Google Fonts

## Objetivo

Practicar la construcción de formularios, el uso de estilos avanzados con CSS y la creación de una interfaz web visualmente atractiva.

## Autor

Proyecto realizado como ejercicio de práctica de frontend.
